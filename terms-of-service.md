## 1. Introduction

Welcome to TORN Bank Management (TBM), a Discord application designed to provide account linking, virtual banking management, balance tracking, deposit and withdrawal requests, loan requests, and support features for players of the online game TORN.

By adding, accessing, or using the TBM Discord Bot, you agree to these Terms of Service. If you do not agree, you must stop using the application.

## 2. Description of the Service

TORN Bank Management provides the following features:

- Linking a Discord account to a TORN player account.
- Verifying TORN account identity using a TORN API key.
- Displaying linked account information and recorded bank balances.
- Managing deposit, withdrawal, and loan requests.
- Calculating and displaying applicable virtual interest rates.
- Providing support tickets, announcements, and system status information.

The bot maintains banking records in its database. TORN cash transfers are not automatically executed by the bot. Deposits and withdrawals are carried out manually by authorized bank staff.

## 3. TORN API Keys and Account Security

To link a TORN account, users must provide a valid TORN API key with sufficient permissions to verify their identity and retrieve their player information.

A Public Only API key is sufficient. A full-access API key is not required.

By using the account-linking feature, you acknowledge that:

- Your API key is submitted through the bot's private account-linking interface.
- API keys are stored in encrypted form in the bot's database.
- API keys are used for account verification and retrieving the relevant TORN identity information.
- API keys are not intentionally shared with other users or third-party services.
- You should never post your API key in public Discord channels or share it with other users.
- You can use `/unlink_account` to unlink your account and request deletion of the stored API key.

You are responsible for using an appropriately restricted API key and keeping your credentials secure.

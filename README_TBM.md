# TORN Bank Management (TBM)

**TORN Bank Management (TBM)** is a Discord bot that provides virtual banking features for players of [TORN](https://www.torn.com/).

TBM helps players manage their in-game banking activity directly through Discord.

## Features

- **Account linking** – securely connect your TORN account to the bot.
- **Balance tracking** – view your TORN account balance through Discord.
- **Deposits and withdrawals** – submit deposit and withdrawal requests.
- **Loan requests** – submit loan requests through the bot.
- **Banking information** – use `/bank_info` to view the available banking commands and how to use them.
- **Support** – access the bot's support features.

## Connect Your TORN Account

To link your TORN account, TBM uses a TORN API key to verify your identity and retrieve the information needed for its banking features.

### Required API permissions

To let TBM retrieve your TORN account balance, your API key must include the **`user:money`** permission.

You can use either:

- a **Limited** API key with the required permission, or
- a **Custom** API key with **`user:money`** enabled.

Only provide your API key through the bot's designated account-linking process. Do not post your API key in a Discord channel or send it to other users.

Follow the bot's account-linking instructions in Discord to connect your account.

## Commands

- `/bank_info` – explains the available commands and how to use them.
- `/supporttbm` – opens the support process on a Discord server where TBM is installed.

Other commands and features may depend on the bot's current configuration. Use `/bank_info` in Discord for the current command list.

## Support

For help, use `/supporttbm` on a Discord server where TBM is installed.

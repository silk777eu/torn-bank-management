3. TORN API keys and permissions

A TORN API key is used to verify the TORN player identity. The bot also makes requests to TORN for money information in banking workflows. A Public Only key may be sufficient for identity verification, but features that retrieve money information require a key with the relevant user:money permission (for example, an appropriately configured Limited Access key or Custom key).

Use the least-privileged key that supports the features you choose to use. Never post your API key in public Discord channels or send it to support staff. The key is stored encrypted in the bot database using Fernet encryption. Encryption does not eliminate all security risks; protection also depends on the operator securely managing the encryption key and hosting environment.
